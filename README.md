# Geoclient Documentation

This branch contains the source for the Geoclient documentation website: <https://mlipper.github.io/geoclient/>.

## Documentation Website

The content for this site is generated from [Asciidoctor](https://asciidoctor.org) mark up, built using [Gradle](https://gradle.org) and published using [GitHub Pages](https://docs.github.com/en/pages).

## Generating project documentation

```sh
# Checkout the geoclient project
git clone https://github.com/mlipper/geoclient

# Change to the project directory
cd geoclient

# Optional:
# Checkout the branch you want to build the documentation from if it's not main
git checkout next

# Run a clean, full build followed by the asciidoctor task
./gradlew clean build asciidoc
```

If the build completes successfully, the site files will be in the `geoclient/documentation/build/docs/asciidoc/` directory.
