# distribution

This module assembles a single distribution archive for release packaging.

## What it includes

The `distZip` and `distTar` tasks package:

- `service/geoclient.jar` from `:geoclient-service:dockerJar`
- `docs/` generated by `:documentation:asciidoctor` (including API Javadoc at `docs/api/`)
- `license.txt` and `notice.txt` from `src/dist/`

## Build

From the repository root:

```sh
./gradlew :distribution:distZip
./gradlew :distribution:distTar
```

The archives are written to:

- `distribution/build/distributions/`
